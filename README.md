# Определение ботов по поведению пользователей

Проект по классификации пользовательских cookie на людей и ботов на
основе их поведенческой активности на платформе объявлений.

## О проекте

Задача проекта --- для каждой `cookie_id` оценить вероятность того, что
пользователь является ботом. На вход модели поступают данные о cookie и
журнал пользовательских событий, а на выходе формируется числовой
`score` от 0 до 1.

Основная идея решения заключается в том, чтобы представить
последовательность действий каждой cookie в виде набора поведенческих
признаков и использовать их для бинарной классификации.

В работе последовательно выполняются:

-   исследовательский анализ данных (EDA);
-   анализ распределения целевой переменной;
-   проверка качества и структуры журнала событий;
-   удаление полных дубликатов;
-   нормализация категориальных значений платформ;
-   выделение событий, попадающих в соответствующие временные окна;
-   сравнение поведения людей и ботов;
-   построение агрегированных признаков на уровне `cookie_id`;
-   обучение модели CatBoost;
-   подбор гиперпараметров с помощью Optuna;
-   временная кросс-валидация;
-   оценка качества на отложенных временных интервалах;
-   формирование итогового файла с предсказаниями.

## Данные

Для обучения и построения предсказаний используются три набора данных:

-   `train.csv` --- информация о cookie и целевая переменная `target`;
-   `test.csv` --- cookie, для которых необходимо получить итоговый
    score;
-   `events.csv` --- журнал событий пользователей.

В `train.csv` содержится 11 091 cookie. В журнале событий представлены
данные по 16 000 cookie за период с 6 по 26 апреля 2026 года.

Каждое событие содержит информацию о времени действия, типе события,
платформе, объявлении, категории, локации, поисковом запросе, типе
продавца, параметрах страницы поиска и координатах курсора.

## Исследовательский анализ

В ходе EDA исследуются различия между людьми и ботами по нескольким
группам характеристик:

-   частота и типы пользовательских действий;
-   используемая платформа;
-   тип продавца;
-   распределение активности по часам суток;
-   разнообразие действий;
-   количество просмотренных объявлений, категорий, локаций и поисковых
    запросов;
-   наличие и характер пропусков;
-   временные интервалы между событиями;
-   особенности движения курсора.

Для каждого пользователя поведенческие данные рассматриваются внутри
соответствующего временного окна.

## Формирование признаков

Для каждой `cookie_id` формируется набор агрегированных признаков,
описывающих поведение пользователя.

В него входят:

-   количество событий и количество уникальных типов событий;
-   количество уникальных объявлений, категорий, локаций и поисковых
    запросов;
-   продолжительность активности;
-   интенсивность событий;
-   интервалы между последовательными действиями и их статистики;
-   количество сессий;
-   доля активности в ночное время;
-   доля коротких и нулевых интервалов между событиями;
-   статистики движения курсора;
-   количество и доли различных типов событий;
-   соотношения между отдельными действиями;
-   доли активности по платформам;
-   распределение активности по часам суток;
-   характеристики поисковой активности;
-   наличие координат курсора;
-   возраст cookie.

Идентификаторы `cookie_id`, целевая переменная и календарная дата окна
непосредственно в модель не передаются.

## Модель

В качестве основного алгоритма используется `CatBoostClassifier`.

Сначала строится baseline-модель с фиксированными параметрами. Затем
выполняется подбор гиперпараметров с использованием `Optuna`.

При подборе учитывается временная структура данных: более ранние даты
используются для обучения, последующие даты --- для проверки. Последние
два дня обучающей выборки сохраняются как отдельный holdout и не
используются при подборе гиперпараметров.

Оптимизация проводится по основной метрике задачи ---
`Precision@Recall>=70%`.

## Оценка качества

Для оценки модели используются:

-   `Precision@Recall>=70%` --- основная метрика;
-   `PR-AUC`;
-   `ROC-AUC`.

Baseline CatBoost на отложенных временных данных показал:

-   Precision@Recall≥70%: **0.7765**
-   PR-AUC: **0.7529**
-   ROC-AUC: **0.9339**

После подбора гиперпараметров итоговая модель показала:

-   Precision@Recall≥70%: **0.7128**
-   PR-AUC: **0.7409**
-   ROC-AUC: **0.9351**

После финального обучения на всей обучающей выборке модель формирует
вероятностные оценки для объектов `test.csv`.
